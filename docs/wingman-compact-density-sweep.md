# Wingman Compact Density Sweep

## Purpose

This pass reduces wasted space across the app while keeping the cleaner dashboard style.

## Applied globally

- Main app content padding reduced.
- Topbar height reduced.
- Page width increased from narrow centred layouts to a wider 1500px working area.
- Hero panels reduced in height and padding.
- Dashboard/task cards reduced in height and internal padding.
- Route cards use auto-fit grids to fill available width.
- Buttons use smaller rounded rectangles.
- Form controls are shorter.
- Drawers and support panels are reduced.
- Sidebar navigation spacing is reduced.
- Proposal remains readable but is more compact.

## Design rule

Wingman should show the current task clearly without using oversized panels or empty margins.
