# Trusted tester release checklist

Before giving access to trusted testers:

- [ ] `npm run typecheck` passes.
- [ ] `npm run build` passes.
- [ ] `npm run verify` passes or known non-blocking audit items are documented.
- [ ] Git branch is clean or remaining changes are intentionally parked.
- [ ] Home page visually checked.
- [ ] Templates page visually checked.
- [ ] Compare page visually checked.
- [ ] Settings page visually checked.
- [ ] Call Coach page visually checked.
- [ ] Discovery flow checked with one real scenario.
- [ ] Finder checked with one real scenario.
- [ ] Product Pitch checked from Finder or Compare.
- [ ] Proposal output checked for assumptions and missing information.
- [ ] Known limitations shared with testers.
- [ ] Feedback form shared with testers.
