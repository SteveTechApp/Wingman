# Wingman trusted in-house testing pack

## Purpose

This pack is for controlled internal testing of WyreStorm Wingman.

Wingman should be tested as:

- a sales qualification assistant;
- a guided AV discovery assistant;
- a product direction assistant;
- a competitor comparison assistant;
- a proposal starter.

Wingman must not yet be treated as:

- a final quoting engine;
- a complete system design authority;
- a replacement for official datasheets;
- a replacement for pre-sales review on complex projects;
- a customer-facing autonomous recommendation tool.

## Tester group

Start with 3 to 5 trusted internal testers:

- one technical pre-sales person;
- one sales manager or BDM;
- one less technical sales user;
- one distributor-facing user;
- optionally one support or technical services user.

## Test objective

The test is successful if Wingman helps users:

1. ask better customer questions;
2. identify likely application type;
3. select a safer WyreStorm product direction;
4. spot missing information;
5. avoid wrong product-class recommendations;
6. produce customer-safe first-pass wording;
7. know when to escalate to pre-sales.

## Tester instruction

Please test with realistic opportunities, not perfect examples.

Report:

- what worked;
- what confused you;
- where the product direction looked wrong;
- where a dependency was missing;
- where wording sounded too confident;
- where the UI felt too large, cramped or unclear.
