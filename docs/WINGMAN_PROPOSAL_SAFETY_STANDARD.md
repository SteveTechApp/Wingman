# Wingman Proposal Safety Standard

Wingman must be commercially useful without overclaiming.

## Required output sections

Every proposal-ready output should separate:

- Confirmed requirement
- Design assumptions
- Recommended architecture
- Required WyreStorm products
- Optional enhancements
- Risks / needs validation
- Next steps

## Avoid unsafe claims

Avoid:

- guaranteed
- fully compatible
- will work in all cases
- best product
- exact equivalent

## Use validation language for

- installed cable route
- USB generation
- audio / Dante / AES67 requirement
- control protocol
- regional SKU availability
- network capability
- display behaviour
- camera compatibility
- product lifecycle status

## Compare outputs

Competitor comparison should label each result as one of:

- Direct match
- Partial match
- Category match only
- No credible WyreStorm equivalent
- Needs manual review
