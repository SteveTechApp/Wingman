# Wingman Short Workflow Pages

## Purpose

This pass reduces page length and moves explanation into Guru.

## Changes

- Shared workflow pages now expose the main task first.
- Supporting evidence, warnings, diagrams and design reasoning are collapsed by default.
- Guru includes a call-notes interpreter.
- Users can paste notes or use browser speech capture where supported.
- Interpreted notes can be sent into Discovery.

## Product rule

Wingman should guide one workflow action at a time.

Main page:

- ask;
- capture;
- recommend next action.

Guru:

- explain why;
- explain meaning;
- suggest next question;
- interpret call notes into AV design.
