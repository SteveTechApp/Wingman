# Wingman Dashboard Workflow Menu

## Purpose

This pass makes the Dashboard a simple front door rather than another information-heavy page.

## Main question

What are you trying to do?

## Primary routes

- Start a customer call
- Paste notes or transcript

## Continue routes

- Build the AV requirement
- Find a product direction
- Compare a competitor
- Create customer follow-up
- Open existing opportunity

## Rule

Dashboard should route the user to the right workflow quickly. Supporting explanation belongs in Guru or the destination page, not on the dashboard.
