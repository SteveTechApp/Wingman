# Product Update CSV Schema Guide

Generated by `npm run product-update:schema-guide`.

Use this guide when preparing real WyreStorm and competitor source files for `data-imports/incoming`.

## Operating rule

- Do not edit governed `*-current.csv` files directly for routine updates.
- Prepare incoming `*-source.csv` files first.
- Run `npm run product-update:check-incoming` before promotion.
- Run `npm run product-update:promote-incoming` only after preflight passes.
- Competitor rows are for comparison and positioning only, never WyreStorm BOM output.

## Minimum review checklist

- WyreStorm active/current products are separated from discontinued, unlisted, do-not-spec and review-only items.
- Matrix output counts distinguish routed outputs from mirrored, loop, local monitor and auxiliary outputs.
- AVoIP rows separate 1G and 10G families and do not imply cross-series interoperability.
- USB, audio and control fields are populated where they materially affect system design.
- Competitor fingerprints identify product class, role, I/O, bandwidth/resolution and relevant USB/control notes where known.
- Unknown competitor data is marked for review rather than treated as verified.
