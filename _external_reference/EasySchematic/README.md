# EasySchematic reference area

This folder is for local review only.

Do not copy EasySchematic source code into Wingman without licence review.
Do not commit extracted third-party files from selected-files or extracted.
Use docs/easyschematic-wingman-reference-audit.md as the review summary.

The rule that keeps an extraction out of history is one level up, in
`_external_reference/.gitignore`, because it has to cover the whole pen and not
this folder alone. Keep it there rather than adding a second one here: two
copies of that list is how the two stop agreeing about what is ignored.
